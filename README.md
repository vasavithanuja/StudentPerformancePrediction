# TaskFlow - To-Do List

TaskFlow is a simple and responsive To-Do List web application
that helps users manage their daily tasks.

## Features

- User Registration
- User Login
- Add Tasks
- Edit Tasks
- Delete Tasks
- Mark Tasks as Completed
- Dashboard
- Profile Page

## Technologies Used

- HTML
- CSS
- JavaScript
